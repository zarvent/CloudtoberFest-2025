# CloudtoberFest 2025 · Santa Cruz

Aquí encontrará el material, resúmenes y el sitio web conmemorativo del CloudtoberFest 2025. Evento técnico celebrado en Santa Cruz y organizado por la Comunidad de AWS Bolivia.

El archivo `index.html` es el punto de partida que enlaza a todo el contenido.

## Sobre el Evento

CloudtoberFest 2025 fue una jornada dedicada a profundizar en prácticas de infraestructura moderna sobre AWS. El objetivo fue reunir a la comunidad local para compartir conocimientos sobre automatización, redes en la nube y despliegues estáticos.

* **Fecha:** 29 de octubre de 2025
* **Lugar:** Santa Cruz, Bolivia
* **Repositorio:** <https://github.com/zarvent/CloudtoberFest-2025>

## Charlas Técnicas

Estas fueron las three charlas principales del evento. El material y los resúmenes de cada una están en este repositorio.

| Charla | Ponente(s) | Descripción | Material |
| :--- | :--- | :--- | :--- |
| De cero a alta disponibilidad para HTTP con Terraform y AWS | Cesar Tablero | Diseño de servicios HTTP resilientes, cubriendo replicación, balanceo de carga y redundancia automatizada mediante Terraform (IaC). | Ver Charla |
| Understanding AWS VPC: A first dive into cloud networking | Carlos Isaac Jaldin Benavides | Introducción a los componentes esenciales de una VPC (CIDR, subredes, Gateways) usando la analogía de un "condominio privado". | Ver Charla |
| Crea tu propia web con S3 en AWS | Dariana Pol Aramayo & Nicole Lozada Leon | Proceso paso a paso para desplegar sitios estáticos en Amazon S3, configurando buckets públicos y el ciclo de petición/respuesta. | Ver Charla |
